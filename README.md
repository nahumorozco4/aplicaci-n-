# Teyvat Tracker v3

Tracker Android/PWA de ahorro para Genshin Impact, rediseñado tomando como referencia las capturas proporcionadas.

## Incluye
- Diseño mobile-first muy cercano al dashboard de referencia.
- Progreso: deseos + protogemas/160 + pity.
- Cálculo automático de protogemas y deseos necesarios por día.
- Inventario separado: rosados, azules y sin clasificar.
- Polvo y brillo estelar.
- Canjes mensuales configurables.
- Registro de saldo actual.
- Actualización de pity y 50/50/garantizado.
- Historial, deshacer, exportar/importar y reinicio.
- Navegación inferior funcional.
- PWA offline con Service Worker.
- Proyecto Android WebView listo para abrir en Android Studio.

## Generar APK
La carpeta `android/` es un proyecto Android estándar. Ábrela en Android Studio, deja que sincronice Gradle y ejecuta `app > Build > Build APK(s)`.

El entorno de esta sesión no tiene Android SDK/Gradle instalado, por lo que aquí no se pudo producir el binario `.apk`; sí queda preparado el proyecto para compilarlo.
